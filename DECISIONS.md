# Decision log

Every design decision that shaped Bayana, newest first: what was decided, the reasoning
behind it, who decided, and which part of the design it governs. This file is the
project's chronology and the place to look when asking "why is it like this, and when did
it change." It is a single table, running from today back to the first commit on
2026-06-03.

**How this file works**

- **Append a new row whenever a decision is made or reversed.** Do not edit history in
  place: an entry's date and the ordering of rows never change. Rows may be *trimmed* for
  brevity as long as the facts recorded nowhere else survive.
- **The design itself lives in [SPEC.md](SPEC.md)**, which is the source of truth for how
  the system works today. The detailed analysis of rejected options is SPEC §14; this
  table is the at-a-glance history. The **Ref** column names the SPEC.md section each
  decision governs.
- **Task state lives in [TODO.md](TODO.md)**, which tracks open work only. Decisions do
  not go there.

| 2026-07-25 | **CSP gains two development-only relaxations: `'unsafe-eval'` in `script-src` and `ws:`/`wss:` in `connect-src`**, both gated on `NODE_ENV === "development"` so the production header is byte-identical to before. | The CSP added on 2026-07-10 broke local development: React's development build calls `eval()` to reconstruct cross-environment callstacks for its error overlay, and Turbopack's HMR runtime evaluates hot-updated modules, so the dev server threw `eval() is not supported in this environment`.
